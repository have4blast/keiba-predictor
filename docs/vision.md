# ビジョンドキュメント — 競馬予想AI

## 1. 何を作るか (What)

netkeiba.com からスクレイピングした過去レースデータを用いて、  
LightGBM による機械学習モデルで **勝率・複勝率を予測** し、  
Streamlit ダッシュボードで閲覧・意思決定支援を行うシステム。

---

## 2. なぜ作るか (Why)

- 競馬予想は膨大な要素（馬・騎手・調教師・コース・オッズ等）が絡み合い、人手での分析には限界がある
- 機械学習により、7カテゴリ・数十特徴量を統合した客観的な予測が可能になる
- バックテストによるROI計算で予測精度の定量評価が可能

---

## 3. MVPスコープ (Scope)

### 含む
- 過去レースデータのスクレイピング（netkeiba.com）
- SQLite によるデータ永続化
- 特徴量エンジニアリング（7カテゴリ）
- LightGBM による勝利・複勝予測モデル
- Streamlit ダッシュボード（予測表示・バックテスト・DB状況）
- データリーク防止機構

### 含まない（将来拡張）
- リアルタイムオッズ自動更新（スケジューラー）
- 払い戻し金額の自動計算・推奨購入額
- 海外レース対応
- モバイル対応UI

---

## 4. 成功基準 (Success Criteria)

| 指標 | 目標値 |
|------|-------|
| 単勝的中率 | ベースライン（人気順）を上回る |
| 複勝的中率 | 35%以上 |
| バックテストROI | -15%以上（元返し以上を目指す） |
| データ収集速度 | レートリミット遵守（2〜3.5秒/ページ） |
| 予測レスポンス | 1レース分の予測 < 5秒 |

---

## 5. ステークホルダー (Stakeholders)

| ロール | ニーズ |
|--------|-------|
| 競馬ファン（予測者） | 翌日レースの出走馬スコアを一覧で見たい |
| データ分析者 | 特徴量重要度・バックテスト結果を分析したい |
| システム管理者 | スクレイピング進捗・DB状況を確認したい |

---

## 6. 制約・前提条件

- netkeiba.com の利用規約を遵守（過度なアクセス禁止）
- 個人利用の範囲での使用
- Python 3.11 以上の環境
- インターネット接続が必要（スクレイピング時）
