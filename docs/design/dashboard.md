# Streamlit ダッシュボード設計 — 競馬予想AI

## 1. アプリ構成

```
dashboard/app.py                  ← エントリポイント（マルチページ設定）
dashboard/pages/
    predictions.py               ← 予測結果表示
    backtest.py                  ← バックテスト・成績分析
    data_status.py               ← データ状況・DB管理
```

---

## 2. 共通レイアウト（app.py）

```python
# app.py の役割
# - st.set_page_config でタイトル・アイコン設定
# - サイドバーにナビゲーションリンク
# - モデル・エンコーダの @st.cache_resource ロード

st.set_page_config(
    page_title="競馬予想AI",
    page_icon="🏇",
    layout="wide",
    initial_sidebar_state="expanded"
)
```

**サイドバー構成:**
- 予測結果 (predictions)
- バックテスト (backtest)
- データ状況 (data_status)
- モデル情報（学習日時・AUC）

### テーブルカラム

| カラム | 説明 |
|--------|------|
| 順位 | 勝率スコア降順 |
| 枠番 | post_position |
| 馬名 | horses.name |
| 騎手 | jockeys.name |
| 調教師 | trainers.name |
| 馬齢・性 | 例: 4歳牡 |
| 斤量 | handicap_weight |
| 単勝オッズ | win_odds |
| 人気 | win_odds_rank |
| 勝率スコア | win_score (%) |
| 複勝スコア | place_score (%) |
| 馬体重 | horse_weight (増減) |

### インタラクション
- レース選択: `st.tabs()` または `st.selectbox()`
- テーブル: `st.dataframe()` で行クリック選択可能
- 予測実行ボタン: `st.button("予測実行")` → `Predictor.predict()` を呼び出す

## 6. パフォーマンス最適化

| 手法 | 用途 |
|------|------|
| `@st.cache_resource` | モデル・エンコーダのロード（セッション間でキャッシュ） |
| `@st.cache_data` | DB読み込み結果（TTL=300秒） |
| Parquet 読み込み | 特徴量データの高速読み込み |
| `st.spinner()` | 予測・バックテスト実行中の待機表示 |
